# 服务器挂了怎么办？我的业务会停吗？

**不会全面瘫痪。** 设计上有两层保障：

1. **Agent 本地可独立运行**：即使 Hub 连不上，每个 Agent 仍然可以正常接待客户、写记忆到本地。Hub 只负责"查别人"和"调度"，不负责"干活"。

2. **记忆写入零依赖**：`write_memory` 不需要 Hub 响应也能继续工作（推荐场景下客户端先缓存本地，Hub 恢复后同步）。

3. **恢复后自动重连**：Hub 重启后，Agent 的心跳机制会自动重连。离线期间的记忆可以补传到 Hub。

**一句话：小二还是能正常接单，只是主管暂时看不到日报。**
