# 跟共享文件夹 / 共享 Excel 有什么区别？

**共享文件夹的问题：**
- 谁都能看，没有级别控制
- 文件多了找不到，没有搜索
- 没有披露审计，出了事不知道谁泄密

**Sync Hub 的区别：**
- 写入隔离：Agent 写的内容默认只有自己能看到
- 渐进披露：主管只能看摘要，不能看完整对话
- 搜索驱动：写的时候打标签（如"色差"、"橱柜"），查的时候按标签查

**一句话：共享文件夹是"全部公开"，Sync Hub 是"刚好够用"。**
